Method

  • Stream. Each run sends one fixed, seeded stream of requests in order (a small worker pool keeps a handful in flight). Every request carries X-cb-cache: semantic, X-cb-debug: true and an expiry long enough for the whole run. A per-run tag in the system prompt keeps runs from hitting each other's entries (the system prompt is part of the cache key).
  • Standard vs semantic. The gateway tries an exact lookup before the vector search. A HIT replays the stored response with its original id, which names the request that stored it: the same user message means a standard (exact) hit, a different one a semantic hit.
  • Tokens saved. A HIT replays the stored usage, which is what Bedrock reported when the answer was first generated and cached. That is counted as saved input and output.
  • Embedding tokens. In semantic mode the gateway embeds the last user message on every request that is not an exact hit, and reuses that vector when it stores a miss. The harness embeds the same text with the same model through the gateway's /v1/embeddings and records the token count Bedrock returns.
  • Closest-match score. The gateway reports a score only on a hit, so the harness keeps its own copy of the stored vectors and logs the closest match for every request (shadow_score). Its search is exact where the gateway's index is approximate.
  • Other thresholds. The report replays the cache over all logged embeddings at each threshold, with the gateway's rules (exact first, then the closest stored entry, misses are stored). The replay at the applied threshold is shown next to the measured rate as a check.
  • Latency. Client-measured time for the chat request, from the harness host.
  • Wrong hits. A seeded sample of 100 semantic hits is judged by an LLM with caching off: does the returned answer fit the question asked? A person can override each verdict in the UI.
  • Cost. List prices per million tokens: Sonnet 4.6 $3 / $15, Haiku 4.5 $1 / $5, Titan embeddings v2 $0.02. Cost without cache counts a hit's replayed usage as what it would have cost.
